[한국어](USER_GUIDE.md) | [English](USER_GUIDE.en.md) | **日本語** | [简体中文](USER_GUIDE.zh-CN.md)

## 1. 必要なもの

| 項目 | 内容 |
|---|---|
| PC | Windows 10 / 11。.NET Framework 4.8 は Windows に標準搭載 |
| ドライバー | **Ocean Optics OmniDriver**（x86）。本プログラムには同梱されていないため、先にインストールしてください |

## 2. インストール

### 2.1 OmniDriver のインストール

Ocean Optics から入手した OmniDriver のインストーラーを先に実行します。完了すると通常
`C:\Program Files (x86)\Ocean Optics\OmniDriverSPAM\OOI_HOME` のようなフォルダーに `NETOmniDriver-NET40.dll` ができます。
分光器を USB で接続し、Windows が認識していることも確認してください。

### 2.2 セットアップファイルのダウンロード

[GitHub Releases](https://github.com/Myungsam/UVVIS-Measurement/releases/latest) から `UV-VIS_meas-Setup-2.3.1.exe` をダウンロードします。
ファイルが正しいかは PowerShell で確認できます。結果がリリースページの SHA-256 値と一致する必要があります。

```powershell
Get-FileHash .\UV-VIS_meas-Setup-2.3.1.exe -Algorithm SHA256
```

### 2.3 セットアップウィザード

セットアップを実行します。**「Windows によって PC が保護されました」** と表示されたら **詳細情報 → 実行** をクリックします。
コード署名をしていないオープンソース版のため表示される警告です。
ウィザードは韓国語と英語に対応しています。日本語の Windows では最初に言語選択の画面が出るので **English** を選んでください。以下は英語画面です。

（この最初のダイアログの **キャンセル** ボタンは Windows が表示するため、Windows の表示言語になります）

**② ライセンス** — MIT ライセンスです。**I accept the agreement** を選び **Next**。

![インストール先](images/guide-en/i03_dir.png)

### 2.4 初めて起動するとき

- スタートメニューの **UV-VIS meas** から起動します。
- OmniDriver が自動で見つからない場合はフォルダー選択ダイアログが開きます。`NETOmniDriver-NET40.dll` がある `OOI_HOME` フォルダーを選ぶと、
  次回からは聞かれません。このダイアログで **No** を選ぶとデモモードで起動します。
- プログラムは **同時に 1 つだけ** 起動できます。起動中にもう一度起動すると、開いているウィンドウが前面に出ます
  （分光器は 1 つのプログラムしか開けないためです）。

  **測定データは削除されません**（ユーザーが選んだ保存フォルダーにあるためです）。

## 4. 測定条件の決め方

測定前に信号の大きさを合わせておくと、結果のノイズが大きく減ります。

1. 分光器の表で、測定する分光器の **Use** だけにチェックを入れます。
2. 光源をつけ、空のキュベット（または溶媒）を入れた状態で **Start measurement**（`F5`）をクリックします。
3. **Sample / Dark / White Ref.** タブ（`Ctrl+3`）で信号の最大値を見ます。
4. 最大値が装置のフルスケール（Flame-S は 65535 counts）の **約 50–85 %** になるよう、表の **Integration time** を調整します。
   - ステータスバーに **`SATURATED`（飽和）** と出たら積分時間を短くします。飽和した領域の吸光度は信頼できません。
   - 信号が小さすぎる場合は積分時間を長くするか **Average** を増やします。平均回数を 4 倍にするとノイズは約半分になります。
5. **Set Min Interval** は画面更新間隔の下限です。長時間の時間変化測定では、間隔を長くするとファイルが小さくなります。

> 積分時間や平均回数を変えたら、**取得済みの Dark と White は取り直してください**。信号の大きさが変わるためです。

## 5. 吸光度の測定

吸光度は試料がどれだけ光を吸収するかを表します。プログラムは 3 つのスペクトルから計算します。

```
A = -log10( (S - D) / (W - D) )

S : 試料を入れたときの信号        D : 光を遮ったときの信号（Dark）
W : 空のセル・溶媒を入れたときの信号（White、基準）
```

順序は **Start → Dark → White → 試料** です。Dark と White はクリックした瞬間に **画面に表示されているスペクトル** を保存するため、
必ず先に測定を開始してください。

### 5.1 測定開始

**Start measurement**（`F5`）をクリックすると、ステップ ① に緑のチェックが付き、スペクトルが更新され続けます。
**Sample / Dark / White Ref.** タブで、入ってくる光をそのまま見られます。

![測定中の生スペクトル](images/guide-en/02_raw_running.png)

### 5.2 Capture Dark — 光を遮って

光源のシャッターを閉じるか、不透明なもので光路を遮ります。グラフがベースライン付近で平らになったら **Capture Dark**（`Ctrl+D`）をクリックします。

- 光源を消して再点灯する方法では出力が安定するまで待つ必要があるため、**シャッターを使う方が便利です。**
- Dark は分光器のベースライン（電気的オフセット）と周囲光をまとめて差し引きます。室内照明も実際の測定時と同じにしてください。

> **デモモード** では、仮想光源のシャッターが GPIO 0 に接続されています。**Hardware Settings** タブ（`Ctrl+6`）で
> 分光器 [0] の **GPIO 0 → Direction `Output`、Output `HIGH`** にすると光が遮られます。
>
> ![デモモードでシャッターを閉じる（GPIO 0 = Output / HIGH）](images/guide-en/03_shutter_closed.png)

光が遮られると、グラフはノイズだけのベースライン（デモでは約 1000 counts）になります。

![光を遮った状態](images/guide-en/04_dark_signal.png)

**Capture Dark** をクリックすると赤い線（Dark）が保存され、ステップ表示が ③ White に進みます。
ステータスバーに、どの分光器のスペクトルを保存したかと平均値が表示されます。

![Dark 取得後](images/guide-en/05_after_dark.png)

### 5.3 Capture White — 空のセル（溶媒）で

シャッターを開け、**試料を溶かした溶媒だけを入れたキュベット**（または空のセル）を入れます。信号が安定したら **Capture White**（`Ctrl+W`）をクリックします。
緑の線（White 基準）が保存され、ステップ表示が ④ に進みます。

![White 取得後](images/guide-en/06_after_white.png)

> White は必ず **試料と同じ溶媒・同じキュベット** で取得してください。溶媒とキュベットの吸収・反射が打ち消され、
> 試料だけの吸光度が残ります。

### 5.4 試料の測定

キュベットに試料を入れると、**Absorption** タブ（`Ctrl+1`）にすぐ吸光度スペクトルが表示されます。
下はデモ試料の吸収が最も強くなった瞬間で、420 nm と 520 nm の吸収帯が見えます。

![吸光度スペクトル](images/guide-en/07_absorbance.png)

- 吸光度 0 は White と同じ量の光が透過することを、**1 OD は光の 10 % だけが透過する** ことを意味します。
- 吸光度は **約 0.1–1.5 OD** の範囲で最も正確です。これより大きい場合は試料を薄めてください。透過光が少なすぎるとノイズが大きくなります。
- グラフが空いている波長は値を計算できない部分です（光がほとんどなく `S − D` や `W − D` が 0 以下）。意図的に空けています。

### 5.5 解析バー — スムージング、ピーク、カーソル、濃度

吸光度グラフの上のバーで表示を変えられます。**この処理は表示だけに適用され、保存される CSV は測定値のままです。**

![スムージングとピーク表示、カーソル値](images/guide-en/08_analysis.png)

| 項目 | 使い方 |
|---|---|
| 表示方式 | Absorbance (OD) / Transmittance (%T) / Raw counts |
| Smooth | Savitzky-Golay スムージング。**window (px)** が大きいほど滑らかですが、狭いピークは低くなります。通常 9–21 px |
| Peaks | ピークに赤いマーカーと波長を表示します。図のように **ノイズのピークまで拾う場合は min. height を上げてください**（例：0.020 → 0.1） |
| ベースライン補正 | ベースラインが傾いている・浮いている場合に。`Baseline: zero at`（吸収のない 1 波長）、`Baseline: line between`（2 点を結ぶ直線）、`Baseline: rubber band` |
| Open spectrum... / Clear overlays | 保存した CSV を点線で重ねて比較します（`Ctrl+O`） |
| 読み取り行 | グラフ上にマウスを置くと **カーソル位置の値**、**最も高いピーク**、**モル吸光係数** が表示されます |

**モル吸光係数（Beer-Lambert）** — *Save datasets* の **Concentration** と **Cell Thickness** を入力すると、カーソル位置で `ε = A / (c · l)` を計算します。
図の仮想データでは次のとおりです。

```
A = 0.7314 OD (520 nm),  c = 50 uM = 5.0×10⁻⁵ mol/L,  l = 10 mm = 1 cm
ε = 0.7314 / (5.0×10⁻⁵ × 1) = 1.463×10⁴ L/(mol·cm)
```

濃度と厚さには単位を付けて入力できます：`50 uM`、`0.05`（数値だけなら mM）、`1.5 M` / `10 mm`、`1 cm`、`10`（数値だけなら mm）。

**透過率（%T）** で見るには表示方式で **Transmittance (%T)** を選びます。`%T = 100 × 10^-A` です。

![透過率の表示](images/guide-en/09_transmittance.png)

### 5.6 保存

**Save spectrum**（`Ctrl+S`）をクリックすると、保存フォルダーに次の名前で CSV ができます。

```
<試料名>_spectrum_<日付>_<時刻>.csv        例) Demo-dye_spectrum_20261029_082548.csv
```

ファイル先頭の `#` 行には測定条件（装置、積分時間、平均回数、トリガー遅延、基準の状態、飽和の有無）が記録され、
その下に波長ごとのデータがあります。Excel でそのまま開けます。仮想データの一部は次のとおりです。

```
# Sample,Demo-dye
# Concentration (mM),50 uM
# Cell thickness,10 mm
# Integration (ms),1.000
# Scans to average,4
# Absorbance,A = -log10((S - D) / (W - D))
# Reference state,[0]* Dark: OK  White: OK
# Saturated,no
Wavelength (nm),Sample (counts),Dark (counts),White reference (counts),Absorbance (OD)
420.0191,1081.2946,993.20897,1176.4824,0.31819431
520.0903,1121.5532,990.75193,1681.4119,0.72265239
550.0337,1279.2316,991.72321,1894.2847,0.49682633
```

`Sample`、`Dark`、`White` の列も保存されるので、吸光度を自分で再計算して確かめられます。
520 nm の行では `(1121.55 − 990.75) / (1681.41 − 990.75) = 0.1894`、`−log10(0.1894) = 0.7227 OD` で、保存値と一致します。

> CSV の列名と `#` 行は、ほかのプログラムが読めるよう常に英語で記録されます。

## 6. 蛍光の測定

蛍光は、励起光を受けた試料が **別の（より長い）波長で発する光** を測るものです。吸光度と違って **White 基準は不要** で、
計算式なしに **強度（counts）** をそのまま見ます。

### 6.1 装置の配置

- 励起光と分光器のファイバーは通常 **90°** に配置し、励起光が直接分光器に入らないようにします。
- 励起側にバンドパスフィルター、分光器側にロングパスフィルターを置くと、散乱した励起光が減ります。
- 蛍光は弱いため、積分時間を吸光度より **長く**（数百 ms 以上）とることが多くあります。4 章のとおり **飽和しないこと** を確認してください。

### 6.2 測定手順

1. 吸光度を測定していた場合は、まず **Clear Dark / White** で既存の基準を消します。
2. 積分時間と平均回数を決めます（4 章）。その後 **Start measurement**（`F5`）。
3. **Capture Dark**（`Ctrl+D`）：**溶媒だけのキュベットに励起光を当てた状態** での取得をおすすめします。ベースラインと一緒に溶媒の散乱
   （ラマン散乱を含む）と周囲光も差し引かれます。ベースラインだけを差し引く場合は励起光を遮って取得します。
4. 試料のキュベットに替え、**Fluorescence** タブ（`Ctrl+2`）を見ます。
5. **Save spectrum**（`Ctrl+S`）。White は取得しません。このとき CSV には `Wavelength (nm)`、`Sample (counts)`、`Dark (counts)` の 3 列だけが保存されます。

![Fluorescence タブ（生の counts）](images/guide-en/10_fluorescence.png)

> 上の図はデモモードの画面です。仮想分光器は透過光だけを模擬するため、**実際の蛍光スペクトルではなく光源スペクトル** が
> 表示されています。画面の配置と使い方を示すための例です。

### 6.3 Fluorescence タブに表示される値

Fluorescence タブは、分光器が読み取った **生の counts をそのまま** 描きます。**Dark を差し引いていない値** なので、ベースライン（オフセット）も見えます。
蛍光信号だけを使うには、保存した CSV で `Sample − Dark` を計算してください。下は説明用の仮の数値です。

| Wavelength (nm) | Sample (counts) | Dark (counts) | 蛍光 = Sample − Dark |
|---|---|---|---|
| 560 | 1,410 | 1,002 | 408 |
| 580 | 3,950 | 1,004 | 2,946 |
| 600 | 6,820 | 1,001 | **5,819**（最大） |
| 620 | 4,710 | 998 | 3,712 |
| 650 | 1,880 | 1,003 | 877 |

Excel では `Sample` が B 列、`Dark` が C 列のとき、新しい列に `=B2-C2` と入力して下へコピーします。

**発光ピーク波長を求める** — **Absorption** タブの解析バーで表示方式を **Raw counts** にし、**Smooth** と **Peaks** にチェックを入れると、
蛍光スペクトルのピーク波長が表示されます。読み取り行の `Peak … nm` が最も高いピークです。
ピークは周囲との高さの差で探すので、ベースラインが一定なら結果は同じです。ただし **min. height は最大 10 までしか設定できない** ため、
counts 表示ではノイズのピークも表示されることがあります。スムージングの window を広げると減ります。

> 日付や条件の異なる蛍光強度を比べるには、積分時間・平均回数・励起光の強さ・ファイバーの位置を同じに保つ必要があります。
> counts は相対値であり、装置間の絶対比較には別途校正が必要です。

## 7. 時間変化の測定

反応速度（カイネティクス）や安定性のように、吸光度が時間とともにどう変わるかを記録します。先に 5 章の Dark と White を取得してください。

1. **Timed Absorption Series** タブ（`Ctrl+4`）で **Trace wavelength (nm)** を入力し **Add** をクリックします。複数の波長を同時に追えます。
2. **Record timed datasets**（`Ctrl+R`）をクリックすると記録が始まります。ボタンが **Recording - click to stop** に変わります。
3. 追跡波長の吸光度が時間に沿って描かれます。下の仮想データでは、試料の吸収が時間とともに変化する様子が見えます。

![時間変化の吸光度](images/guide-en/11_timed.png)

4. **Timed Absorption Series (2D plot)** タブ（`Ctrl+5`）では、横軸が時間、縦軸が波長、色が吸光度を表します。
   **Auto scale** を外すと Min / Max (OD) を自分で決められます。

![時間変化の吸光度 2D](images/guide-en/12_heatmap.png)

5. もう一度クリックすると記録が止まります。**Save timed spectra**（`Ctrl+Shift+S`）で全体を保存します。

**測定中のディスク記録（データ保護）** — 記録中は、メモリと同時に次の 2 つのファイルへ **1 行ずつすぐに** 書き込みます。
プログラムが異常終了しても、それまでのデータは残ります。

```
<試料名>_timed_live_<日付>_<時刻>_absorbance.csv     行 = 測定時刻、列 = 波長ごとの吸光度
<試料名>_timed_live_<日付>_<時刻>_counts.csv         行 = 測定時刻、列 = 波長ごとの生の counts
```

メモリには最新の 5000 件だけを保持し古いものから捨てますが、ディスクのファイルにはすべて残ります。
**Save timed spectra** はメモリ上のデータを同じ形式で保存します（`..._timed_<日付>_<時刻>_absorbance.csv`）。

```
Elapsed (s),Timestamp (UTC),178.8000,179.1376,179.4752,...
116.8430,2026-10-28T23:25:54.7510601Z,0.051050305,0.026433554,-0.03545706,...
117.1022,2026-10-28T23:25:55.0103759Z,0.085171446,0.033534959,-0.024552224,...
```

> 光源の明るさが時間とともに変わると、吸光度も一緒に動きます。2 台目の分光器で光源を同時に監視して補正する
> **リアルタイム基準補正** は [リファレンスマニュアル §6](README.md#6-흡광도-계산과-dark--white-reference)（韓国語）を参照してください。

## 8. 測定メソッドファイル

同じ条件で繰り返し測定するときに使うファイルです（`.uvmethod`）。

- **File → Save measurement method**：最小測定間隔、平均回数、分光器ごとの積分時間・トリガー遅延・役割、追跡波長、表示・処理の設定を保存します。
- **File → Load measurement method**（`Ctrl+M`）：保存した条件を再び適用します。分光器は **シリアル番号** で照合します。
- **Dark / White は含まれません。** 基準はその日の光源と溶媒にだけ有効なので、メソッドを読み込んだ後も **取り直してください**。

## 9. よくある問題

| 症状 | 確認すること |
|---|---|
| 分光器が 0 台と表示される | USB 接続、OmniDriver のインストール。ほかの測定ソフト（OceanView など）が装置を開いていないか |
| もう一度起動しても新しいウィンドウが出ない | 正常です。起動中のウィンドウが前面に出ます |
| 「Windows によって PC が保護されました」 | 署名していない配布のためです。**詳細情報 → 実行** |
| 吸光度がノイズだけ | 光源がついているか、Dark を光を遮って取ったか、White を空のセルで取ったか |
| ステータスバーに `SATURATED` | 積分時間を短くし、Dark と White を取り直す |
| Capture Dark / White が効かない | 先に測定を開始してください。画面に表示中のスペクトルを保存する方式です |
| ピークが多すぎる | スムージングをオンにするか min. height を上げる |
| 測定中に光が途切れる | 光源とファイバーのコネクターを確認。プログラムは光源を制御しません |
| Fluorescence タブのベースラインが 0 でない | 正常です。Dark を差し引いていない生の counts です（6.3） |

そのほかの症状と原因は [リファレンスマニュアル §10](README.md#10-문제-해결)（韓国語）にあります。
エラーが起きると `%LOCALAPPDATA%\UV-VIS_meas\error.log` に記録されます。問い合わせの際はこのファイルを添付してください。
